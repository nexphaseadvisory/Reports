How the Index Works

What it measures. The index ranks the 50 states on the grid infrastructure already in place for large new loads, from measured public data only: where utility-scale generation is queued to connect to the grid, how many substations show strong or moderate queue activity, and how fast retail electricity sales have grown.

What it does not measure. It does not measure load-serving capacity: whether a utility can serve a new large load at a given site. A high score points to strong transmission; a utility service availability study still has to confirm spare capacity and timelines.

How to use it. Use it to pre-screen markets before utility outreach. High-scoring states warrant further diligence. For any state, confirm large-load service timelines with the utility.

How it is scored. Each state gets a score from 1 to 10. A state with no retail sales data is scored on the other measures; missing data never counts against it. Scores refresh weekly.

This report does not replace a utility service availability confirmation. It is a pre-screening tool that identifies power-advantaged markets for further diligence.
